## Overview

This release marks the first Governance milestone of the AI Software Development Framework.

It establishes the governance foundation used for future Framework evolution while leaving Runtime, Architecture and existing Reference Implementations unchanged.

---

## Governance

This release introduces the Framework governance foundation:

- **GOVERNANCE.md** defines the governance lifecycle, evidence categories that justify evolution, the Framework First Principle, and the relationship among Architecture Governance, Design Governance, and Implementation Governance.
- **GD-001** establishes Mandatory Design Review before implementation for Framework evolution and official Reference Implementations.
- Governance Decisions (`GD-###`) record binding governance rules for Framework stewardship without replacing ADRs or Framework Assets.
- Evidence classification and the Governance Decision lifecycle improve how Framework evolution is assessed and recorded.
