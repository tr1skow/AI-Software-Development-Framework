## Alt text

Documentation map for the AI Software Development Framework. README is the
primary entry point at the centre and references five destinations: Whitepaper
(understand the architecture; optional but recommended), ADRs (architectural
authority), Framework Assets (working guidance), Framework 0.7 Alpha Adoption
Guide (evaluate and establish Project Integration), and Framework Invocation
Guide (day-to-day operational reference). A hands-off arrow connects Adoption
to Invocation. Note: AI assistants use the same discovery path. Informative
only; not a Runtime workflow.
